# 자주 쓰는 쿼리

점검·확인·통계처럼 **반복해서 쓰는 조회**를 모아둡니다.

## `db/` 와 무엇이 다른가

| | `db/` | `queries/` |
|---|---|---|
| 목적 | **구조를 바꾸는** SQL | **조회·확인**하는 SQL |
| 실행 | 한 번만 (순서대로) | **필요할 때마다 반복** |
| 파일 수정 | ❌ 이력이므로 고치지 않음 | ✅ 개선하면 고쳐도 됨 |
| 예 | `create table`, `alter`, 정책 생성 | `select`, 통계, 점검 |

**`db/` 는 역사, `queries/` 는 도구**입니다.

## 실행 위치

> 🗄️ **Supabase 대시보드 → SQL Editor**

⚠️ **SQL Editor 는 관리자 권한으로 실행되어 RLS(행 단위 보안)를 우회합니다.**
여기서 보인다고 해서 일반 사용자에게도 보이는 것은 아닙니다.
**권한이 제대로 걸렸는지 확인하려면 SQL Editor 가 아니라 `curl` 이나 실제 페이지로 테스트**하세요.

## 🔒 개인정보 주의

일부 쿼리는 **신청자 이름·연락처**를 화면에 출력합니다.
- 결과를 캡처하거나 공유하지 마세요
- 내보낸 CSV 는 `db_backup/` 에 두고 **git 에 올리지 마세요** (`.gitignore` 에 등록돼 있음)

## 파일 목록

| 파일 | 용도 |
|---|---|
| `check-policies.sql` | **보안 점검** — 정책과 권한이 의도대로 걸렸는지 |
| `manage-admins.sql` | 관리자 추가·제거·확인 |
| `applications-stats.sql` | 신청 내역 조회·통계 |
| `storage-check.sql` | 첨부 파일 상태 점검 |

## 쓰는 법

파일을 열어 필요한 쿼리 한 덩어리만 복사해서 SQL Editor 에 붙여넣고 실행합니다.
파일 전체를 한 번에 실행하도록 만든 것이 아닙니다.

새로 자주 쓰게 된 쿼리가 생기면 **여기에 추가**하세요.
